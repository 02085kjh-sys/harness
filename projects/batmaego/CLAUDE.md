# Claude Code 지시

루트 `AGENTS.md`(공통)와 이 폴더의 `AGENTS.md`(밭매고 규칙)를 먼저 읽고 따른다. **논문 규칙은 읽지 않는다.** 아래는 Claude Code에만 해당하는 추가 사항.

## 오케스트레이션

- 너는 설계와 검토만 맡는다. 구현 · 단순 작업은 Opus / Sonnet 서브에이전트에게 위임한다.
- 전체 오케스트레이션은 너에게 일임한다. 오버 엔지니어링 없이 효율적으로 레인을 배치한다.
- 위임 결과는 네가 검토하고 통과/반려만 결정한다.

## Effort

- 이 프로젝트에 high나 xhigh 쓸 필요 전혀 없다. 기본 medium, 단순 작업 low.
- 배치 엔진 정밀 로직 검토만 예외적으로 high.
- 모르겠으면 매 작업 착수 전 권장 Effort를 먼저 제시한다.
