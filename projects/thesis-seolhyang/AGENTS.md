# 설향 딸기 창업논문 — 프로젝트 규칙

계정 공통 규칙(`~/.aside/u/0/AGENTS.md`: 레인 배치·Effort·작업 시작 루틴)을 따르고, 여기엔 이 논문에만 해당하는 것만 둔다.

## 프로젝트 파일 지도

워크스페이스 `~/Desktop/논문 준비 자료/` — 구조는 `README_폴더안내.md`가 원본.

| 폴더 | 용도 |
|---|---|
| `0_발표/<N차_날짜>/` | 차수별 발표 세트 4종(PPT·시연 엑셀·대본·치트시트). 항상 이 4종. |
| `1_제출본/` | 실제 제출본. 수정 금지 |
| `2_작업중/논문본문/` | 본문 docx·초안 md·질문지·번호대장 |
| `2_작업중/근거기록_엑셀.md` | 수치 출처·이유 기록 |
| `3_교수님자료/` | 강의자료·녹취 정리 |
| `8_이전버전_사용금지/` | 열지 말 것 |

최신본 판별: 엑셀 ⑧ 상품화율 90%·달성률 90→100→110%, 3년차 매출 419,215천원.

## 발표 일정 구조 (교수님 지시 2026-09-08)

- 1차(완료): 엑셀 ①②⑦⑧⑩⑪ + PPT
- **2차**: 논문 Ⅰ장 머리말 + Ⅱ장 농장현황 **본문 집필** → 요약 PPT
- **3차**: 논문 Ⅲ·Ⅳ·Ⅴ장 (엑셀 ⑫~⑱ 중심)
- 최종: 통합. 엑셀은 발표 주제가 아니어도 계속 병행.

## 논문 체제 (선배 논문 기준, 교수님 승인)

Ⅰ 머리말(1인칭 "~습니다"체, 2쪽) → Ⅱ 농장현황(1.농장개요 2.생산품목 3.생산기술및재배방법) → Ⅲ 영농환경분석 → Ⅳ 농장비전및영농목표 → Ⅴ 영농계획수립 → Ⅵ 맺음말 → 참고문헌 → 감사의 글 → 부모님 동의서 → 부록. Ⅱ장부터 평서체. 전체 목차·엑셀 매핑: `2_작업중/논문본문/논문_목차_전체.md`.

## 형식 규칙 (교수님 공통 지시, 감점 항목)

- 표·그림 번호는 **논문 전체 연속** (챕터 리셋 없음). `표 1. 제목` / `그림 1. 제목`. 번호는 `_논문체제_및_번호대장.md`에서 받아 쓴다.
- **표 캡션은 위, 그림 캡션은 아래.** 캡처·인용마다 `출처 : 기관, 자료명(연도)`.
- 표목차·그림목차 별도. 실명은 가운데 글자 마스킹(박○현). 참고문헌은 교수님 예시 양식.
- **GPT 티 금지**: "효과적으로·다양한·중요한 역할" 류 상투어, 나열식 불릿, 완결형 부제 금지. 초안은 반드시 **사용자가 직접 읽고 자기 문장으로 고치는 단계**를 거친다. 사용자 실제 경험(실습농장 아침에딸기 더하우스, 외할아버지 벼농사)을 본문에 넣어 개인성을 확보한다.
- **넣지 말 것**: 인력사무소·법인·외국인 근로자 언급 일체 (사용자 명시).

## 산출물 디자인 기준 (사용자 최우선 요구)

- **가장 중요한 건 디자인과 전달력.** 글자만 빽빽한 PPT는 실패. 처음부터 디자인된 상태로 만든다.
- 스펙 원본: `0_발표/_PPT_디자인스펙.md` — 16:9, 크림 배경 #FAF6F2, 카드 흰색+베이지 테두리 #EBDFD5, 글자 #2E2321/보조 #938077, 강조 빨강 #C8394A·금색 #E2A63B·초록 #3E7C4A, Noto Sans KR.
- 매 장 = 섹션라벨(한글) → 제목 34pt → 부제(질문형) → 구분선 → **왼쪽 차트/표 + 오른쪽 숫자 카드 레일** → 하단 출처 7pt(+본인 판단 한 줄).
- 숫자 있는 장은 반드시 도표. 금지: 10pt 미만, 8열 초과 표, 200자 초과 설명, ◈ 소제목 남발, 영문 라벨, "감사합니다" 장, 스톡 이미지.
- 대본은 장마다 4블록: [한 줄 요약] [이렇게 말한다](40자 이내 문장) [이건 이런 뜻] [찔리면 이렇게]. 어려운 말은 그 자리에서 풀이.
- 재사용 스크립트: `scripts/ppt_charts.py`(bar/card/note), `scripts/ppt_diet.py`(글자 다이어트).
