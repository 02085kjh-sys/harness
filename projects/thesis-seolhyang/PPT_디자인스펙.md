# PPT 디자인 스펙 (2차부터 적용) — 사용자가 고른 레퍼런스 기준

레퍼런스: 동료 발표자료 「딸기(설향) 촉성재배 영농계획」 11장 (2026-09-08 사용자 제공).
사용자 평: "숫자와 내용이 한눈에 들어오고 전달성이 좋았다." 이 구조를 그대로 쓰되 **AI 티를 빼는 조정**을 더한다.

## 2. 매 장 고정 골격 (좌표 cm)

```
(1.3, 0.6)  섹션 라벨      8pt 회갈색   예: "02 · 중장기 영농목표"   ← 영문 대신 한글
(23.6,0.6)  쪽번호         8pt 회갈색
(1.3, 1.3)  제목           34pt Bold 진갈색
(1.3, 3.0)  부제(한 줄)    11pt 회갈색  — 이 장이 답하는 질문 한 문장
(1.3, 3.9)  구분선         22.9cm 폭, 베이지 0.5pt
(1.3, 4.4)  왼쪽 본체      폭 14~16cm × 높이 7~7.7cm  = 차트 / 표 / 도해
(15.9~17.9, 4.4) 오른쪽 숫자 레일  폭 6~8cm = 카드 3~5장 세로 스택 (카드 높이 1.2~2.5cm)
(1.3,13.5)  출처·주석      7pt 회갈색, 한 줄
```

- 숫자 카드: 라벨 9~10pt 회갈색 / 숫자 15~26pt Bold (핵심은 빨강, 나머지 진갈색) / 단위는 숫자 뒤 작게
- 요약 장: 2×3 카드 그리드(7.2×4.1cm), 각 카드 왼쪽에 2mm 색 띠
- 목차 장: 2×3 카드에 "01 자산 현황 / 한 줄 설명"

## 4. AI 티 빼기 (교수님 "GPT스럽다" 대응)

레퍼런스에서 AI처럼 보이는 요소와 대체 방법:

| AI 티 나는 것 | 대신 이렇게 |
|---|---|
| 영문 섹션 라벨 (ASSET SURVEY, SALES PLAN) | 한글 라벨 "01 · 자산 현황" |
| "감사합니다" 마지막 장 | 마지막 장 = **"교수님께 여쭙고 싶은 것 2가지"** 또는 "다음 발표까지 할 일" |
| 모든 카드 크기 동일, 완벽 정렬 | 핵심 카드 1장만 크게(2배), 나머지 작게 — 위계 만들기 |
| 표지 부제가 목차 나열식 | 표지 부제는 **한 문장 주장** (예: "외할아버지 논 옆, 3,000평에서 시작하는 설향 딸기") |
| 완결형 문장 부제 ("~계획", "~추이") | 부제는 **질문형** ("3년차에 얼마나 남나?", "왜 9월에 심나?") |
| 출처만 나열한 각주 | 각주에 **본인 판단 한 줄** 추가 ("최고가 대신 평년가를 쓴 건 과대계상을 피하려고") |
| 차트만 있고 표시 없음 | 차트 위에 **손으로 짚을 지점 1개 강조** (원·화살표·굵은 라벨) |
| 스톡 이미지·아이콘 | **본인 사진**: 실습 농장(아침에딸기 더하우스) 사진, 외할아버지 논, 창업예정지 현장 사진 |
| 모든 장 같은 레이아웃 | 3~4장에 1장은 **사진 전면 + 한 줄 캡션** 장 삽입 (호흡) |
| 발표대본이 슬라이드 읽기 | 대본에 "이 장에서 내 경험 한 마디" 블록 — 실습 때 본 것, 할아버지 말씀 등 |

핵심: **구조는 레퍼런스처럼 정갈하게, 내용은 본인 것으로.** 교수님이 거르는 건 "정갈함"이 아니라 "본인 검토 흔적 없음"이다.
