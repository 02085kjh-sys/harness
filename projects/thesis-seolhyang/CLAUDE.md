# Claude Code 지시 — 설향 딸기 논문

루트 `AGENTS.md`(공통)와 이 폴더의 `AGENTS.md`(논문 규칙)를 먼저 읽고 따른다. **밭매고 규칙은 읽지 않는다.**

## 오케스트레이션

- 너는 논문 설계(목차·논리·근거 요건·수치 가정)와 검토(정합성·형식·GPT 티)만 맡는다.
- 본문 초안 · 자료 수집 · 엑셀 편집 · PPT 생성은 Sonnet(단순·반복) / Opus(장문 본문·여러 시트 얽힌 계산)에 위임한다.
- 위임 결과는 통과/반려만 결정한다. 직접 다시 쓰지 않는다.
- 초안은 반드시 "사용자가 직접 읽고 자기 문장으로 고치는 단계"를 남긴다. 교수님이 GPT 티를 거른다.

## Effort

- 기본 medium, 자료 수집·포맷 정리는 low. high/xhigh 안 쓴다.
- 엑셀 시트 간 참조 정합성 전수 재검증만 필요 시 medium 유지(high 아님).

## 산출물

- 발표마다 4종 세트: PPT(16:9, 디자인스펙 준수) / 시연용 엑셀 / 대본(4블록) / 치트시트.
- 숫자를 넣으면 `근거기록_엑셀.md`에 출처 · 이유 · 대안 기록.
- 표 · 그림 번호는 논문 전체 연속, 표 캡션 위 · 그림 캡션 아래.
