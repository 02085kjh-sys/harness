# 논문 체제 · 표/그림 번호 대장

교수님 지시(9/8): 표·그림 번호는 **논문 전체 연속**. 표 캡션 위, 그림 캡션 아래. 출처 표기.
새 표/그림을 넣을 때마다 여기 등록하고 번호를 받아 쓴다. (챕터 넘어가도 번호 이어짐)

## 논문 전체 순서

1. 제목
2. 요약
3. 목차 / 표 목차 / 그림 목차
4. 1장 머리말 ← 2차 발표
5. 2장 농장 현황 ← 2차 발표
6. 3장 경영계획 ← 3차 발표
7. 4장 손익·수익성 ← 3차 발표
8. 5장 결론 ← 3차 발표
9. 6장 (강의자료 확인 — 향후 계획 또는 부록 안내)
10. 참고문헌 (교수님 예시 양식)
11. 감사의 글
12. 부모님 동의서
13. 부록 (엑셀 시트)

## 표기 예시

```
표 3. 설향 딸기 5개년 월별 평년가격 (단위: 원/kg)
[표]
출처: 한국농수산식품유통공사 KAMIS, 2021~2025년 중도매인 판매가격

[그림]
그림 2. 촉성재배 연간 작업 일정
출처: 농촌진흥청 농사로, 딸기 촉성재배 표준 작업일정 (2026년 접속)
```

## 개인정보 마스킹

- 모델농장 대표 등 실명: 가운데 글자 ○ (예: 박○현)
- 농장명은 지역+업종 수준으로 (예: 담양 ○○농장) — 강의자료 예시 확인 후 확정
