# 근거 기록 템플릿 (엑셀·문서 수치의 출처와 이유)

> 엑셀 셀 옆 각주는 "어디서 가져왔나"만 적고, 이 파일에는 **"왜 이 값을 골랐나"**까지 남긴다.
> 발표 예상질문 답변은 여기서 만든다. 값을 바꾸면 지우지 말고 아래 [변경 이력]에 추가.

## 기록 양식

각 항목은 아래 6줄로 적는다.

```
### [시트] 항목명 (셀 주소)
- 값:
- 출처: 기관 · 자료명 · 연도 · 페이지/URL
- 이유: 왜 이 값인가 (기준 범위, 보수적/중립적 선택 근거)
- 대안: 검토했지만 안 쓴 값과 배제 이유
- 연결: 이 값이 흘러가는 다른 시트/셀
- 확인일:
```
