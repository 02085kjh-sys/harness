# 새 세션 시작 프롬프트 — 설향 딸기 논문

아래 블록을 통째로 복사해서 붙여넣기.

```
하네스 저장소: https://github.com/02085kjh-sys/harness

작업 시작 전에 루트 AGENTS.md 와 projects/thesis-seolhyang/ 안의 AGENTS.md, CLAUDE.md 를 읽고 적용해줘.
밭매고 프로젝트 규칙(projects/batmaego/)은 읽지 마. 이 세션은 논문 전용이야.

너는 설향 딸기 영농창업계획 논문의 설계와 검토만 맡아.
본문 작성 · 자료 수집 · 엑셀 편집 · PPT 생성은 Sonnet / Opus 에게 위임해.
전체 오케스트레이션은 너에게 일임할 테니, 오버 엔지니어링 없이 효율적으로 레인을 배치해.

Effort는 high나 xhigh 쓸 필요 전혀 없어. 기본 medium, 단순 작업은 low.
확실하지 않으면 매 작업 착수 전에 권장 Effort를 먼저 제시해줘.

가장 중요한 건 산출물의 디자인과 전달력이야. PPT는 처음부터 디자인스펙대로 만들고, 숫자 있는 장은 반드시 도표로.
엑셀에 숫자 넣을 때마다 출처와 이유를 근거기록에 남겨.
초안은 내가 직접 읽고 고칠 수 있게 넘겨줘. 교수님이 GPT 티 나면 거르셔.

각 작업 착수 전에 아래 세 줄만 먼저 보여줘.
1. 목표와 완료 기준
2. 권장 Effort와 이유
3. 어느 모델에게 무엇을 위임할지
```
