# 밭매고 · 밭매고맵 하네스

AI 에이전트(Claude, Codex 등)가 이 프로젝트에서 일할 때 지켜야 하는 규칙 모음입니다.

새 세션을 열 때 이 저장소 주소를 넣고 "이 하네스를 검토하고 적용해줘"라고 요청하면,
에이전트가 아래 파일들을 읽고 역할 분담 · Effort · 지키는 원칙을 따릅니다.

## 파일

| 파일 | 내용 |
|---|---|
| `AGENTS.md` | 프로젝트 설명, 지키는 원칙, 역할 분담, Effort 기준 (모든 에이전트 공통) |
| `CLAUDE.md` | Claude Code 전용 지시 (AGENTS.md를 따르고, 추가로 오케스트레이션 방식) |
| `PROMPT.md` | 새 세션 시작할 때 붙여넣는 프롬프트 |

## 사용법

1. 새 세션 시작
2. `PROMPT.md` 내용을 통째로 붙여넣기
3. 에이전트가 "권장 Effort · 위임 계획"을 먼저 제시하면 확인 후 진행
